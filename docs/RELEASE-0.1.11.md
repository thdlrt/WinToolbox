# WinToolbox 0.1.11：稳定字幕与精简导航

字幕改为稳定句级显示。识别服务不断修订的临时文字先在后台缓冲；已稳定的完整句子或短段落才进入显示队列。每段原文和译文使用同一个标识，不再把最新原文配上较早译文，也不再只截取长句尾部。

长句按窗口宽度分屏，留出阅读时间后切换。翻译暂未完成时等待片刻，再以本句原文兜底；迟到译文不改写已经显示的一页。处理明显落后时跳过较早的完整待播段落并提示，避免字幕无限积压。

“原语言”默认自动识别，也可选英语、中文、日语、韩语、法语、德语或西班牙语；“翻译为”选择目标语言。原语言需要停止字幕后再改，显示模式和目标语言可在运行时调整。看英文视频时可以直接选原语言英语、翻译为中文。

任务中心页面、导航、首页最近任务和顶栏跳转已移除。处理进度、取消、失败重试、结果打开及字幕文件编辑移到各工具自己的页面，后台处理和历史数据继续保留。

本次一并包含此前完成的按月记账功能。

接口依据：[百炼流式语音识别客户端事件](https://help.aliyun.com/en/model-studio/fun-asr-client-events)、[Qwen-ASR 实时事件](https://help.aliyun.com/en/model-studio/qwen-asr-realtime-server-events)。当前模型未传语言提示时自动检测；指定语言会发送对应识别参数。

验证（2026-09-11）：230 项 Python 全量测试通过，57 项字幕状态断言通过，28 项字幕主流程与 55 项小窗口布局检查通过；任务中心移除相关 26 项状态及组件断言通过。真实百炼接口处理 35.52 秒连续英文音频，生成 8 个稳定字幕段及对应的 8 段中文译文；首段在开始后 7.17 秒生成，原始接口首个大段最终结果约 19 秒。每个字幕 ID 的原文始终保持不变。网络慢时前端按同句原文兜底，不将迟到译文配给下一句。此为合成英文样例测试，视频实际识别效果仍随声音、口音和网络变化。
