# WinToolbox 0.2.0

## 新增

- 记账支持多个项目、项目归档及按项目统计。现有记录自动归入“AI报销”，保留原有分摊方式；其他项目默认普通收支记账。
- 与 AndroidToolbox 0.4.0 共用 WebDAV 自动合并同步，打开软件、修改后和运行期间自动重试。支持离线录入、字段级合并、冲突选择、删除标记及附件 SHA-256 校验。
- 按项目与指定日期区间导出 XLSX、CSV，金额可直接计算，日期可筛选。
- 新增网络诊断：DNS、TCP 重复连接、TLS 证书和 HTTP 状态；保存的诊断配置跨端同步，诊断历史本机保存并可导出 JSON。
- 记账保存成功后自动关闭编辑窗口；失败保留输入。

## 使用

两端填写相同的 WebDAV 连接和远端目录。Windows 使用设置中的目录，Android 在记账页设置同步目录，默认 `WinToolbox`。无需手动选择账本覆盖方向。完整说明见 [跨设备记账与网络诊断](LEDGER.md)。

同一字段冲突需在页面选择保留内容。删除优先于离线旧修改。原有应用快照备份与恢复保持独立。Android 系统结束应用后将在下次打开继续同步。
