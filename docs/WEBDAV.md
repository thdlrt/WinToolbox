# WebDAV：一个连接，一个根目录

在“设置 → 数据”填写 WebDAV 地址、用户名、密码和根目录。手机和电脑使用同一个根目录后，各工具会自动使用固定子目录，不再单独填写账号或路径。

例如根目录为 `共享名/工具箱`：

| 自动创建的子目录 | 用途 |
| --- | --- |
| `config-backups/windows` | Windows 配置备份 |
| `config-backups/android` | Android 配置备份 |
| `ledger-v1` | 账目、项目、附件、网络诊断配置 |
| `file-relay` | 手机和电脑共用的文件中转站 |
| `project-memory` | 项目记忆 |

根目录的父文件夹需要在服务器上存在；工具箱会创建根目录及所需服务子目录。

## 配置备份与恢复

配置备份由你手动上传。恢复时选择备份并确认，覆盖本机对应配置。恢复前会保存恢复副本，当前 WebDAV 连接保持不变。

- Windows 包括应用设置和支持的工具配置；选中 API 密钥时，需要填写备份密码，密钥只保存在加密备份里。
- Android 包括常用工具、支持的界面偏好和 NAS 非敏感连接配置。密码仍保存在设备上，需要时重新输入。
- 两个平台的配置备份分别保存，防止将 Windows 配置应用到手机。
- 配置恢复不替换账目、附件、文件中转站或项目记忆。需要整机数据恢复时，使用 Windows 的本地完整备份。
- 旧的远端完整快照仍可识别；从云端配置恢复入口只提取其中的配置。

## 数据自动同步

记账和诊断配置在启动、修改后及运行期间自动同步；冲突按记录处理，不选择整份账本的覆盖方向。项目记忆继续按其记录协议同步。文件中转站直接浏览根目录下的 `file-relay`，上传和下载使用同一位置。

所有服务共用已保存的连接。需要换服务或根目录时，只修改此处；旧任务不会被重定向到新地址。

## 升级与旧目录

旧版工具单独保存的路径会作为内部迁移来源保留。访问中转站时自动复制旧文件到新子目录，原文件保留；同名不同内容使用迁移子目录保存，避免覆盖。网络或权限导致迁移失败时，页面显示原因并在后续访问重试。

安卓优先将原来的记账同步根目录作为统一根目录。电脑保留已经配置的 WebDAV 根目录。升级后只需核对两端这个根目录一致。
