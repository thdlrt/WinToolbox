# WinToolbox 0.6.0

新增文件与文件夹占用检查、剪贴板历史和网易云音乐工具，改进飞书来源对话路由。

- **查看 / 解除占用**：快捷菜单支持文件、文件夹和混合选择，递归检查子项，也可查询目录句柄和程序工作目录占用。提供请求关闭与确认强制结束，操作后自动复查，不自动删除文件。新增文件及文件夹的 Explorer 右键入口；系统服务、关键进程、Explorer 和工具箱自身仅供查看。每次最多扫描 5000 个项目，跳过链接及联接，扫描不完整会明确提示。
- **剪贴板历史**：保存本机文字和图片，支持搜索、复制、删除与保留天数设置，默认保留三天；记录不纳入备份与 WebDAV 同步。
- **网易云音乐**：支持本地 NCM 还原与 MP3 转换、公开歌单和喜欢列表的读取与导出；扫码登录后使用账号有权限的下载接口。保留原始文件，不替换音源或绕过平台权限。
- **飞书消息桥接**：私聊和群聊回复可按核实的来源继续对应 Codex 对话；支持群聊待答提问窗口，多个待答对话存在歧义时提示选择，避免路由到无关对话。调整机器人确认文案与群聊授权边界。
- 改进悬浮球及工具入口，更新项目知识和音乐技能说明。

## 下载与更新

仅提供 `WinToolbox_0.6.0_x64-setup.exe` 与 `SHA256SUMS.json`，不再提供便携 ZIP；历史附件保留。更新保留原有数据，发行包不包含个人设置、凭据、模型或使用记录。

强制结束进程可能丢失未保存内容，请先保存文件。占用查询不能保证识别所有驱动或内核占用。网易云和飞书功能需要各自的账号权限或本机 CLI 配置。
