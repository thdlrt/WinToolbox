# 跨设备记账与网络诊断

## 项目与记账

原有账目首次升级后自动归入“AI报销”，保留日期、金额、附件和原有两人分摊方式。可以创建其他项目，例如出差、科研经费或日常开销。新项目默认普通收支统计，也可选择“报销后两人均摊”。归档项目仍可查看和导出历史记录。

Windows 和 Android 都支持新增、编辑、删除账目，按项目和日期查看明细。币种分别统计，不自动换算。等待报销尚未计入已报销金额。

在“两人均摊”项目中，每笔支出可单独勾选“参与两人均摊”。取消后由自己承担，仍计入消费总额、报销统计和普通收支结余，但不计入应均摊金额及双方结算。均摊金额按本区间、本币种中参与均摊且尚未报销的支出合计除以 2，最后按分四舍五入；再减去转账收入得到还需转入金额。已报销的个人支出也不会抵扣其他条目的均摊金额。

原有记录缺少该选项时沿用参与均摊，不自动改写旧账或变更历史；新条目默认勾选，可以逐笔取消。收入和普通收支项目不显示该选项，切换类型或项目会保留原选择。自己承担的支出在列表中标注，CSV/XLSX 导出新增“参与均摊”列。

逐笔均摊使用可选布尔字段 `split_enabled`，随账本同步、备份及冲突处理保留。Android 需升级到本次提供的 0.8.1 或之后包含此功能的版本，旧版校验器不能读取新增字段；未升级的手机不代表已经兼容。新版覆盖安装保留原包名和签名，不会自动操作用户手机。

Android 支持系统文件选择器和调用系统相机拍照添加附件。支持 PDF、PNG、JPEG、WebP、OFD，单份不超过 50 MiB。附件会复制到工具箱私有存储，删除原照片不会删除已保存附件；打开附件时验证大小和 SHA-256。

Windows 编辑条目时，每个已保存附件右侧可直接改选分类（发票、收据、支付记录或其他），改动随条目保存一并提交并进入变更历史；待保存的新附件也可逐个改选分类。条目附件可一键合并导出为单一 PDF：PDF 附件按原页并入，图片按 A4 页面等比嵌入，OFD 不参与合并并在结果中列出；合并结果保存在数据目录 `exports/attachments`，可在任务完成后直接打开。

Windows 选择项目和起止日期后，可导出 XLSX 或 CSV。日期范围包含首尾两天，导出不受关键词等临时列表筛选影响。表格包括项目、日期、收支类型、名称、分类、币种、金额、报销状态、备注、附件名称、条目标识和参与均摊；附件文件本身不嵌入表格。XLSX 的金额为数字、日期为日期单元格，支持继续筛选和计算。

## 配置两端同步

1. 两端设置中配置同一 WebDAV 服务地址、账号和密码。
2. 两端只在全局 WebDAV 设置填写相同根目录，默认均为 `WinToolbox`。记账无需单独设置目录。如果服务器要求共享名，则两端都填写 `共享名/WinToolbox`。
3. 程序在该目录下创建 `ledger-v1`，用于账目、项目、网络诊断配置和附件。文件中转站自动使用同一根目录下的 `file-relay`。

打开软件会自动同步；修改后会触发同步，程序运行期间约每分钟补查一次。Android 被系统结束或强制停止后，待下次打开继续同步。未联网时可以正常记账，连接恢复后重试；同步状态会显示错误和待同步记录。

同步使用独立变更记录，不要求选择“本地覆盖远端”或“远端覆盖本地”，不会自动恢复整个工具箱配置快照。原有整机备份、快照恢复仍按原流程操作。

### 同时修改时如何合并

- 两端分别新增：都保留，重复重试不会产生第二条账目。
- 同一账目修改不同字段：自动合并，例如电脑改分类、手机加备注。
- 同一字段同时修改：保留候选值，页面提示“处理冲突”，选择需要保留的内容。处理前显示一个稳定候选值；汇总和导出按当前显示值计算。
- 一端删除、另一端离线修改：删除优先，旧设备重新连接不会复活账目。如确实还需要该记录，应新建一条。
- 附件按内容校验后传输，上传完成后再发布引用，下载失败不会当作已同步成功。
- 少数跨字段并发修改可能产生需要检查的记录，例如一端改为收入、另一端将金额改为零。此类条目保留并提示检查，不会阻止整个账本打开。

变更历史与删除标记不自动清理，用来保证离线设备合并正确。WebDAV 同步不是加密备份；服务管理员可以读取账目和附件。账号密码仅在各设备本地保存。

## 网络诊断

两端支持保存诊断目标，配置随同一 WebDAV 合并同步。历史诊断结果留在各自设备，不上传。

- 输入域名或 IP：检查 DNS 与 TCP 端口连接，显示多次连接耗时和成功次数。
- 输入 HTTP URL：额外检查 HTTP 响应。
- 输入 HTTPS URL：额外检查 TLS 证书及 HTTP 响应。
- HTTP 401/403 表示服务已响应但需要权限；404 表示路径不存在。它们不等同于网络不通。
- 不跟随 HTTP 重定向，不在诊断地址里保存密码或查询令牌。

诊断检查当前工具箱进程的网络路径，不自动套用浏览器的 HTTP/SOCKS 代理。TCP 连接耗时不是 ICMP ping；回家隧道仍保留原有协议支持范围。

Windows 可导出 JSON 诊断报告，用于对比或排查。


## AI 记账（PC 与 Android）

在项目记账点击 **AI 记账**，选择项目，添加文件、图片或粘贴文字，再点击 **识别为草稿**。一次可提取多笔交易，最多20条。草稿不会自动入账、不会进入 WebDAV 同步；点击每条的 **编辑并确认**，核对名称、金额、日期、币种、收支类型、报销状态与是否均摊，然后点击 **保存** 才产生正式账目。

- 支持 PDF、PNG/JPEG/WebP、TXT/CSV、DOCX/XLSX、带文字的 OFD。扫描 OFD 请先转换为 PDF 或图片。表格中的日期序号、公式缓存和混合币种仍须核对。
- 单批最多5个文件，单个10 MiB、合计20 MiB，文字合计32000字；每份 PDF 最多6页，图片及 PDF 页面合计最多12张。不截取超出限制的页数，超过限制会提示拆分。
- 文字与图片会发送给“AI记账”配置的模型。PC 在 **设置 → 模型服务 → 功能模型 → AI记账** 设置，Android 在 **AI 设置 → AI记账模型** 设置。两端使用相同的 `expense_import` 功能名，可用现有模型配置同步；不会悄悄改用其他模型。
- 金额、日期、币种不明确时留空并提示，必须补全才能保存。模型不能决定是否已报销或是否均摊。发现同日期、金额和名称时提示检查重复；该提示不代表已经准确排重。
- 草稿及材料副本只保存在生成它们的设备，关闭或重启后可继续确认。PDF、图片和 OFD 在确认时预加为附件，可移除；TXT/CSV/Office 仅用于识别，不作为账目附件。确认后账目及附件按原有同步规则处理。
- 同一草稿使用稳定的账目编号，保存成功后即使确认回执丢失，重新打开仍能识别为已入账，避免再次确认产生重复账目。

PC 草稿目录为 `data/expenses/ai-drafts`；Android 为应用私有 `files/ledger-ai`。这些是本机待确认材料，尚不参与跨端草稿同步。
