# WinToolbox 0.1.23

改进悬浮球开合与文件投放操作，减少 WebDAV 重复配置，并新增可跨工具箱重启复用的内存清理授权组件。

- 悬浮球在主窗口打开时也保持显示。使用固定透明画布和原生点击区域，修复收起时闪动；快速开合、点击外部收起和拖放状态统一处理。
- 拖入多个文件或文件夹后自动上传并收回进度小球；完成后显示短暂反馈，再恢复内存读数，不需要手动收起。失败保留可查看的详情，后台上传可排队与取消。
- 文件中转站默认使用设置中的 WebDAV 连接，只需指定中转路径；仍可选择独立连接。共享凭据不重复保存，连接发生变化时拒绝执行使用旧连接的待启动任务。
- 内存清理增加“启用免重复授权”、修复和移除组件入口。首次启用需要一次 Windows 管理员授权，随后通过固定用途的按需清理组件执行；任务注册保留到主动移除，不随工具箱退出而丢失。组件不可用时提示修复，不自动反复提权。

## 下载与更新

Windows x64。安装版运行 `WinToolbox_0.1.23_x64-setup.exe`；便携版完整解压 `WinToolbox-0.1.23-portable.zip` 后运行 `WinToolbox.exe`。更新前退出旧版，保留自己的 `data` 目录。校验值见 `SHA256SUMS.json`。

发布包不含本机账号、密码、用户数据或个人文件。

## 验证范围

- Python 全量 493 项、前端逻辑 11 项、Rust 8 项测试通过。
- 内存组件的权限申请策略、协议及失败路径通过自动化验证。本次发布时本机尚未完成新组件的首次管理员授权，真实提权清理、跨重启免弹窗及内存释放效果尚未完成实机验收。
- Windows 原生拖放可能受目标软件权限级别影响；模拟事件与状态测试不能替代所有设备的资源管理器拖入验收。
