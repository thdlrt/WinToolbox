# 文件中转站

手机和电脑在“设置 → WebDAV”填写相同的连接和根目录，中转站自动使用 `<根目录>/file-relay`。不再设置独立账号、密码或中转目录。

## 设置与使用

在中转站“设置与右键菜单”中只选择本机下载目录与右键集成。连接统一在全局设置管理；修改连接后，排队中的旧任务不会上传到新地址。根目录及服务子目录会自动创建，根目录的父文件夹需在服务器上存在。

升级时自动复制旧中转目录的文件，保留原文件；同名不同内容进入迁移子目录。迁移失败会显示原因并在后续访问重试。

列表提供目录导航、名称筛选、修改时间排序、文件大小和修改时间。点击文件夹进入，点击文件名会先下载，再通过系统默认程序打开。下载文件夹包含子目录和空目录；本机同名文件不会被覆盖，会保存为带随机后缀的新文件。

上传支持选择多个文件、整个文件夹，以及将文件/文件夹拖到中转站窗口。上传目标为当前浏览目录；右键发送的目标始终为配置的中转根目录。同名远端文件拒绝覆盖，失败明细显示在结果中。文件先上传到随机临时名称，成功后用禁止覆盖的 WebDAV MOVE 发布。进度、取消和后台上传记录均在页面内显示。

默认上传后保留本地原文件。可勾选「上传校验后移走本地文件」：每个文件上传后会重新下载计算 SHA-256，核对内容与本地原文件都没有变化，再删除本地原文件。这个选项额外消耗一次下载流量；网络失败、校验失败、目标重名均保留本地文件。目录中的文件逐项处理，空的本地文件夹保留；整批操作不是事务。

## 右键发送

安装版安装时自动注册；便携版首次启动自动注册，并在路径变化或入口缺失时修复。为当前用户添加文件与文件夹的「发送到文件中转站」及「发送到 → 文件中转站」快捷方式，不需要管理员权限。在页面点击「移除右键菜单」会移除两种入口，后续启动不会重新添加；可以手动再次添加。安装版卸载仅清理仍指向本安装目录的入口。重新安装会再次注册菜单。

工具箱没有运行时会启动；已运行时将路径交给已有实例，并显示中转站页面。命令行只有程序路径和所选文件路径，不经过 PowerShell/cmd，不含账号密码。右键发送始终保留本地原文件，不会采用页面中的移动选项。未配置连接时任务会提示先配置，保存后可点击「重新上传」。

这是兼容的传统右键菜单。Windows 11 通常从「显示更多选项」打开；注册为 Document 多选模式，传统命令最多支持 15 项，更多文件可以从工具箱多选或拖拽上传。[微软菜单选择模式说明](https://learn.microsoft.com/en-us/windows/win32/shell/how-to-employ-the-verb-selection-model)

## 上传日志与拖出文件

上传历史、失败详情、重试和取消统一放在「上传日志」二级页面，主页面不再堆叠历史上传结果。

按住文件名可以拖到资源管理器或支持文件拖入的软件；勾选多个项目后，从其中一个文件名拖动即可一起发送。第一次需要下载到工具箱 data/relay-drag-cache 缓存，文件较大时等待准备完成后再次拖动。缓存完成后一分钟内可复用；双击仍可打开文件或进入文件夹。Windows 拖放使用复制模式，不删除 NAS 文件；目标软件决定是导入、打开还是复制。缓存使用本机 data 目录，不向其他软件传递 WebDAV 凭据。

## 按时间清理

选择 1 天、1 周、30 天或 90 天后「预览清理」。范围为配置的整个远端缓存目录（包括子目录），时间根据服务器提供的最后修改时间计算；预览列出全部候选文件、数量与空间，确认后永久删除。空文件夹保留。

预览 10 分钟有效，连接配置改变或重启后失效。执行时重新检查每个文件的版本、时间和大小，并发送 `If-Match` 条件，发生并发修改则跳过。服务器未提供可靠时间或强 ETag 的文件不自动删除，预览会提示跳过数量。目录本身不执行递归 DELETE，避免把刚上传的新文件一起删掉。协议依据：[WebDAV RFC 4918](https://www.rfc-editor.org/rfc/rfc4918.html)。

## 验证与限制

- 单次递归上传、下载、清理最多遍历 20000 个项目；大目录请拆分。
- 不跟随本地符号链接或目录联接，不支持 Windows 不允许的文件名。
- 下载采用本地临时文件和硬链接独占发布，需要支持硬链接的本机文件系统（通常为 NTFS）；不要把本机下载目录选到不支持硬链接的虚拟网盘。
- 测试使用临时文件与本地 WebDAV 服务，覆盖中文/特殊字符路径、同名冲突、原子发布、传输失败、本地移动校验、清理并发修改、过期预览、凭据隔离和右键参数。未填写真实飞牛账号时，无法验证特定 NAS 上的权限、证书与网络可达性。
