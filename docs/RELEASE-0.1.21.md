# WinToolbox 0.1.21

增加 FN API 端口映射，解决局域网设备 API 通过 FN 远程入口时，调用工具无法携带 FN Token 的问题。

- 为指定的局域网 `IPv4:端口` 生成本机 `127.0.0.1:端口`。
- 映射复用已认证的 FN 隧道，不需要开启 TUN，也不需要调用工具理解 FN 登录流程。
- 每条规则支持添加、编辑、启用、停用和删除；本机端口可以自动分配。
- 规则只监听本机，固定使用仅回家范围，并再次校验 NAS 下发的允许网段。
- 断线、重置或退出时关闭监听和活动连接；重新连接后恢复已启用规则。
- 规则随本地备份和 WebDAV 快照迁移，不记录 FN Token、HTTP 请求头或转发正文。

HTTP、HTTPS、WebSocket 及其他 TCP API 可以透明转发。HTTPS 客户端如果严格校验证书，需要让访问主机名与目标证书匹配；UDP 和 IPv6 暂不支持。
