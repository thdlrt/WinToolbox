# WinToolbox 0.1.1

本次更新精简界面，处理功能和数据格式不变。

- 删除宣传标题、英文标语、头像、页脚、导航分组与品牌副标题。
- 设置页直接显示选项卡和服务操作，移除三步引导及重复标签。
- 首页保留工具入口、搜索和收藏。媒体工作台改为单栏与底部操作条。
- 同步精简任务、实时助手、资料问答、Codex 配置、文件整理和扩展工具页面。
- 保留参数提示、错误反馈、数据变更确认、主题切换和侧栏折叠。

验证：TypeScript 与 Vite 构建通过；独立浏览器检查 9 个主页面、5 个设置选项卡及深色/折叠状态，在 1280×860 和 940×640 下无横向溢出，未出现 JavaScript 运行错误。验证数据来自隔离目录，未调用云模型或更改实际 Codex 配置。

截图：`output/playwright/minimal-ui/`。

发行包：Windows x64 安装程序与便携 ZIP 已生成；EXE 版本为 0.1.1，ZIP 完整性检查通过，包内包含 Python、FFmpeg 和 portable.flag，不包含个人数据目录。

升级：退出旧版后运行 0.1.1 安装程序。原有配置和数据继续使用。
