# 工具箱悬浮球

启动后显示悬浮球，主窗口打开时也保留，可同时使用。关闭主窗口后工具箱仍在后台运行。右键悬浮球可收起到托盘；从托盘菜单选择“显示工具箱悬浮球”可重新显示，彻底退出仍使用托盘“退出”。

- 中心为系统物理内存使用百分比，每两秒刷新；悬停显示已用/总内存。
- 按住收起的小球拖动调整位置，位置保存在 data/orb-position.json。展开菜单会限制在当前显示器工作区内，收起时平滑回到原位置。使用固定透明画布与原生点击区域，开合时不再缩放、移动 WebView 窗口；收起后画布的空白部分不拦截其他窗口点击。
- 默认点击展开四个快捷入口：内存清理、文件中转、开启/停止字幕、工具首页。开启字幕同时显示字幕窗。右键提供自定义快捷菜单、内存清理设置、字幕设置、收起到托盘和退出工具箱；Escape 或点击外部关闭菜单，恢复成小球。拖放投放区域不因焦点仍在资源管理器而提前收起。
- 支持一次选择多个文件/文件夹拖进球，展开投放区域并显示数量，松手上传到已配置的中转根目录，始终保留本地文件。同名不覆盖。开始上传后自动回到进度小球；点击小球可展开进度、取消上传或进入中转站，收起不会停止传输。成功后短暂显示勾选与文件数量，再恢复内存读数，不必手动收起；失败保留错误面板，收起后仍可点小球查看。历史在文件中转站的“上传日志”。
- 未配置 WebDAV 时明确提示先配置，不接受无目标的上传。
- 传输中可继续拖入其他批次，按顺序上传；队列最多 32 批，重复投放事件不会重复入队。取消上传同时清空待传队列，失败会暂停队列，可查看问题后继续。队列仅保留在当前工具箱运行期间，完全退出后需重新拖入未开始的文件。
- 动画包括环形菜单展开与反向收起、边缘位置过渡、按下反馈、内存/进度环过渡、拖放区域变形、上传/清理与成功提示；跟随系统减少动画偏好。原生区域收起会等界面过渡结束，快速连续开合会取消过期操作；拖出投放区域有短暂缓冲以避免反复开合。

## 内存清理

工具首页新增“内存清理”。提供物理内存、可用内存、系统提交量和操作历史。手动清理由专用静默进程调用 Windows 内存管理接口：常规模式清理进程工作集与低优先级备用页；深度模式清理进程工作集、修改页及全部备用页，可能短暂卡顿。选择保存在 data/memory-cleaner.json，并同时应用于悬浮球。

首次清理由 Windows 请求一次管理员授权，用于安装固定用途的免重复授权组件。安装后工具箱退出、更新、重新启动及电脑重启都不会丢失授权配置；日常清理不再提权，也不显示命令行或结果弹窗。主窗口和文件拖放保持普通权限。悬浮球和内存页面以小火箭动画显示清理中状态，并按真实返回结果展示完成或失败；跟随系统减少动画偏好。

组件安装在 Program Files 的 WinToolboxMemoryCleaner 下，只允许管理员或 SYSTEM 修改，通过当前账户专用的 Windows 计划任务按需启动；不设置自动清理触发器。当前用户只能读取或启动任务，不能修改其高权限执行目标。本机命名管道拒绝远程连接，仅允许 SYSTEM 与当前账户访问，客户端核对服务端程序路径。只接受常规/深度两种固定操作及状态探测，不接受文件路径、脚本或命令行。空闲一分钟后工作进程退出，下次由计划任务静默唤起；不修改 UAC 设置，不保存管理员密码。

内存设置中可显式修复或移除组件，这两种管理操作需要 Windows 授权；日常清理失败不会自动重装或重复清理。内存差值为前后实测读数，后台活动可能导致负值。

自动清理直接在此页配置占用阈值与定时间隔，复用工具箱自己的清理组件，无需 Mem Reduct。默认关闭，仅在工具箱运行期间生效，隐藏到托盘后继续运行，彻底退出后停止。组件未就绪时暂停自动清理并显示原因，不在后台申请管理员授权。手动和自动任务串行执行，避免重叠；阈值触发后有恢复条件与最短间隔，避免持续高占用时反复清理。

组件启动前会把扩展长度路径转换为普通 Windows 路径，避免 .NET Framework 初始化失败。无法解析响应时记录退出码、标准输出与标准错误，界面提示查看日志，不再一律要求修复组件。更新时旧附带 Mem Reduct 文件移至本地构建备份目录，保留原配置但不再打包或启动。若旧程序仍在运行并占用文件，保留旧文件且提示退出；下次更新再归档，不阻断新版更新。

## 中转文件删除

单个文件右侧“删除”，或勾选多个文件后“删除所选”。确认永久删除后，重新核对文件版本并用 If-Match 删除；文件在选中后变化则跳过。保留本地下载副本。目录不递归删除，需进入目录选择文件；不具备强 ETag 的服务器请使用飞牛文件管理删除。

## 自定义快捷菜单

右键悬浮球 → 自定义快捷菜单，或工具箱 设置 → 常规 → 悬浮球快捷菜单。可从工具箱功能中选择 1–6 项，用上下箭头排序或移除；从顶部开始顺时针排列。恢复默认后点击“保存快捷菜单”生效。保存写入 data/orb-settings.json，并通知已打开的悬浮球即时更新，无需重启。收起到托盘、退出始终留在右键菜单。
