# WinToolbox 0.1.24

- WebDAV 配置同步默认包含 API 服务密钥，覆盖百炼及“其他 API 服务”中的 OpenAI 兼容、Gemini 等服务。
- 密钥随快照加密，必须设置至少 8 位备份密码；另一台电脑输入同一密码恢复后，密钥重新使用接收电脑的 Windows 加密存储保护。密钥和备份密码不会写入任务记录。
- 已有同步配置保留原先选项；关闭密钥同步时，界面明确提示另一台电脑需要重新填写。原来不含密钥的旧快照不能补回密钥，需要从原电脑重新上传。
- 修复英文 Windows 上无法保存中文“发送到”快捷方式的问题，使用 Unicode 原生接口处理中文目录和文件名。
- 保留 0.1.23 的悬浮球流畅性、自动收回进度球、共用 WebDAV 连接与按需内存清理组件改进。

Windows x64，提供安装程序、完整便携包和 SHA-256 校验文件；更新时保留 `data` 目录。

密钥同步使用两套隔离的测试数据验证加密上传、三类 API 服务恢复和接收端重新保护，不使用或发布个人密钥。

内存组件尚未完成本机首次管理员授权后的真实清理验收；首次启用仍需一次 Windows 系统授权。Windows 原生跨窗口拖放仍需结合目标软件与设备环境验收。
