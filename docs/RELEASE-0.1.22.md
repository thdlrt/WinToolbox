# WinToolbox 0.1.22

文件中转站、悬浮球和内存清理整合到工具箱。

- 文件中转站：连接 WebDAV，浏览、上传、下载、打开与拖出文件；上传日志独立入口，按时间预览清理，单个/批量文件删除，安装时注册资源管理器右键上传菜单。
- 悬浮球：关闭主窗口后显示系统内存用量，点击展开快捷菜单；支持 1–6 项自定义与排序，点击外部收起，多文件/文件夹拖入上传。修正 Windows 动态隐藏窗口无法接收拖放的问题。
- 静默内存清理：首次清理接受 Windows 授权后，本次工具箱运行期间复用专用清理进程，不再反复提权或弹出结果窗口。退出工具箱会释放该进程；重新启动后的首次清理仍需授权。
- 小火箭动画显示清理状态，结果使用真实可用内存差值；支持减少动画偏好。常规/深度清理可在工具箱中设置，Mem Reduct 原版自动清理设置仍可独立打开。
- 文件同步：规则管理、预览与执行、版本及冲突处理。
- 项目知识：项目/全局知识、任务与归档、离线记录合并、WebDAV 与 SSH 同步、CLI 接入。
- 独显省电守卫：电源条件与应用 GPU 偏好管理、独显占用及电池状态检查。

Windows x64。安装版会检查 WebView2；便携版完整解压后运行 WinToolbox.exe。发布包不含本机 data、账号密码或用户文件。请保留自己的 data 目录后更新。

本次发布为 Windows 客户端，未包含 Android 安装包。跨窗口拖放的最终实机结果仍需按设备验证，模拟事件验证不等同于资源管理器拖入验收。

验证：Python 全量 483 项通过，后续内存专项 9 项通过，Rust 6 项、任务看板 7 项通过；前端构建及小火箭界面检查通过。权限复用与进程退出已通过协议测试；本机首次提权测试返回拒绝访问，实际管理员清理及其内存效果尚未完成验收。
