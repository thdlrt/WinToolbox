# 快捷菜单与快捷脚本

默认选中文本、文件或文件夹后，长按鼠标中键 450 毫秒呼出。短按保留原按键动作。托盘菜单可直接开关，并进入「设置 → 快捷菜单」调整中键、侧键或键盘组合键、长按时间、自动翻译和固定工具入口。

## 翻译

快捷菜单使用独立的 `quick_translate` 功能分配，默认复用已有阿里云供应商和密钥，选择 `qwen3.8-flash`。模型说明见[阿里云官方文档](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)。原有字幕翻译分配保持原值；可在「设置 → 模型 → 功能分配」单独修改。

选中外语后触发菜单，自动请求翻译。单词显示音标、释义，段落显示完整译文。读取密码框时拒绝取值，链接、邮箱、路径、疑似口令和密钥不会自动翻译。此过滤是启发式识别，普通单词组成的口令无法仅凭文本准确判断。

翻译前在本地判断目标语言：以中文为主的选区（允许少量英文术语）、有明确文字特征的日语/韩语，以及可确认的常见英文会静默跳过请求，翻译区域留空。更改目标语言后会重新判断；中文也可以翻译到英文等目标语言。短词和共用拉丁字母的语言可能难以区分，无法确认时保留翻译，不额外调用模型判别语言。

选区读取使用 Windows UI Automation 和 Explorer 选中项，不模拟复制，也不读取剪贴板历史。未提供选区接口的应用可进入快捷脚本页面手动输入。文本最多 6000 字符，文件最多 100 项。没有后台持续监听或翻译选中文本。

## 快捷脚本

工具首页的「文件整理」替换为「快捷脚本」。内置 11 项带图标的动作：解散文件夹、复制路径、提取文件名、SHA-256、多行合并、字数统计、JSON 格式化、URL 编解码、Base64 编解码。各动作可开关并配置触发条件；条件只影响推荐，执行需要点击。

解散文件夹先列出内容移至上一级的预览，再确认执行。同名目标、父子文件夹同时选择、符号链接及目录联接会拒绝执行；预览过期或文件变化需重新预览。只删除移空后的文件夹，失败时尝试回滚已移动项目并保留操作记录。

可添加本机 `.py`、`.ps1`、`.exe` 脚本，并选择文本、外语、文件、文件夹等触发条件。Python/EXE 接收 `--context <临时 JSON 文件>`，PowerShell 接收 `-ContextPath <临时 JSON 文件>`；文件包含 `text`、`paths`，任务结束后删除。标准输出作为结果，最多保留末尾 16000 字节，最长运行 60 秒。脚本拥有当前用户权限，只添加可信脚本。

## 资源与数据

原生输入钩子等待按键，选区读取器只在触发时启动，4 秒超时退出。菜单页面按需加载，隐藏约 30 秒后销毁。最多保留 32 份选区和 32 条短期翻译缓存；选区与内置动作结果不写入任务参数或历史结果。自定义脚本自行输出的内容会进入该任务日志。

配置位于便携版 `data/quick-menu.json`，翻译分配沿用 `data/settings.json`。关闭自动翻译可仅使用本地动作和固定工具。

## 查看并解除文件占用

文件或文件夹右键 → **显示更多选项** → **查看并解除文件占用**，会直接打开检查结果；也可以选中文件、文件夹或混合项目后长按快捷菜单按键，再点击 **查看 / 解除占用**。右键入口处理单个项目，长按快捷菜单支持一次选择最多 100 个项目。文件夹递归检查子项，并查询文件夹本身的直接占用和工作目录占用。每次最多扫描 5000 个文件和文件夹，跳过符号链接、目录联接；超过上限、遇到不可访问路径或不支持的文件系统时提示“扫描不完整”，不会显示全量检查通过。便携版首次启动自动添加文件及文件夹右键入口，可在快捷菜单设置中移除。

结果显示占用程序名称、PID、程序路径，以及文件当前是否因占用阻止删除。先保存内容，再使用“请求关闭”；程序不响应时可确认“强制结束”。强制结束会关闭整个进程，包括它打开的其它文件，未保存内容可能丢失。操作后自动重新检查，文件不会自动删除，可回到资源管理器重试删除。

使用 Windows Restart Manager 查询可识别的进程，并通过获取和关闭 DELETE 权限句柄检测当前阻塞，不修改文件。没有查到进程不保证没有驱动或内核占用；“权限不足”也不等同于进程占用。系统服务、关键进程、Explorer、工具箱和无法核对身份的进程不提供结束按钮，需要手动处理。普通权限操作失败会提示手动关闭或以管理员身份重试，不自动提权。实现依据：[RmGetList](https://learn.microsoft.com/en-us/windows/win32/api/restartmanager/nf-restartmanager-rmgetlist)、[RM_PROCESS_INFO](https://learn.microsoft.com/en-us/windows/win32/api/restartmanager/ns-restartmanager-rm_process_info)、[TerminateProcess](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-terminateprocess)。

目录直接占用补充使用 Windows Native API 的 [FileProcessIdsUsingFileInformation](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wdm/ne-wdm-_file_information_class)；此信息类为系统保留接口，文件系统不支持时报告不完整扫描。进程操作前核对 Windows 服务列表、会话、启动时间和关键进程标记；无法核对服务列表时，目录占用进程仅供查看。目录结果汇总子项的阻塞状态，问题列表最多显示 200 项。
