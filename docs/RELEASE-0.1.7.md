# WinToolbox 0.1.7

新增“口语练习”：英文生成后保存为完整 WAV 和分句音频。支持本地回放、播放速度调整、单句循环，以及选择片段或单词单独生成。相同文字、声音、模型和服务地址复用已验证音频，播放和查音标不请求 API。

单词音标来自随软件提供的 CMUdict 美式发音词典，使用音素到 IPA 的转换；保留多读音，未收录词明确提示。词典转换不根据上下文判断多音词。

原数据和 API 配置保留，开发阶段继续使用固定免安装目录。完整音频可从练习或任务输出中打开；切换声音、模型或首次生成新选段会产生新的 API 请求。

使用：打开“口语练习”，输入英文，点击“生成并播放”。点击句子左侧播放按钮重听；播放方式选择“单句循环”，速度选择 0.75× / 1× / 1.25×。点击英文单词查看音标，点击“生成词发音”才请求独立单词音频。拖选文本后可点击“朗读选中文字”。“已保存”中可随时打开过去的练习。

验证：158 项 Python 全量测试通过，随后新增的中断重试缓存测试通过（口语练习共 6 项集成测试，词典 19 项验证），播放器 41 项断言通过。真实百炼生成两句“The meeting starts at nine. Please send the report today.”，共 3.68 秒；再提交两次均复用全部缓存。将生成的 WAV 交给真实语音识别接口回读，两句内容完整一致。

本次生成文件位于 `.build/practice-real/practice/audio/`，验证脚本为 `.build/validate_practice.py`。最终安装后的原生回放验收因 Windows 锁屏暂未完成；未尝试操作锁屏或登录界面。

浏览器隔离示例数据下的布局已在 1280×900、940×900 检查通过，无横向溢出；截图在 `output/playwright/practice/`，不是用户实际练习记录。真实合成试听文件：`output/practice-0.1.7-example.wav`。
