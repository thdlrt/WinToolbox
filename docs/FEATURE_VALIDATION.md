## 迁移链路覆盖

集成测试创建两个真实 `App` 实例，分别使用不同数据目录，运行真实 SQLite、线程任务中心、插件进程和 Windows DPAPI。测试向第一个实例写入临时 API 测试密钥、资料和工具，生成加密备份后恢复到第二个实例。

- 恢复后的资料原文件位于新目录，关键词/向量检索仍可返回内容和来源。
- 插件清单恢复后，文件哈希工具仍由真实子进程运行，散列与原文件一致。
- API 密钥先从源 DPAPI 解密后进入加密归档，再由目标实例重新使用 DPAPI 保护；普通设置接口不返回明文。
- 自定义 `output_dir` 中已登记的任务结果被复制到新媒体目录，SQLite 内任务结果和 artifact 路径同步更新。
- 外部配置媒体库连同录音/视频及 JSON 引用重定位；未勾选媒体时不会删除当前目录已有录音。
- 恢复引擎数据库时保留正在运行的导入任务记录，轮询 `jobs.get` 不会短暂出现“任务不存在”。

这些集成测试使用同一台 Windows 的两个目录和同一测试用户。实际跨机器、跨 Windows 用户的安装体验需要另一台设备验收；测试已经覆盖便携加密格式、路径迁移与 DPAPI 重新保护过程。
