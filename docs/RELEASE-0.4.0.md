# WinToolbox 0.4.0

模型设置改为直接管理供应商和各功能模型。移除全局“阿里云 / 本地模式”面板，按每个功能分别选择云端供应商或本地模型，并将模型安装入口改为“本地模型管理”。

- 功能模型提供阿里云预设一键分配，保留现有供应商与密钥，应用后仍可逐项修改。
- 文件转写、实时识别、翻译、问答、语音合成等独立路由；旧全局模式不再阻断功能分配。
- 新增 Android 取件文本、取件图片模型角色，可分别指定 OpenAI 兼容供应商与模型。
- AI 配置及 API Key 通过统一 WebDAV 固定子目录加密同步；使用现有 WebDAV 密码，两端无需新增目录或密码配置。
- 下载先预览确认，仅替换 AI 配置，保留其他设置和业务数据。

配套 AndroidToolbox 0.6.0 提供短信/图片 AI 取件助手。详见 [AI 配置同步协议](AI-CONFIG-SYNC.md)。
