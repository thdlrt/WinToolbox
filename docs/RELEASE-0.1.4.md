# WinToolbox 0.1.4

本版根据真实英文视频和已配置百炼 API 的功能测试修复字幕体验。

- 长字幕显示末尾的新内容；英文识别继续时保留最新中文译文。
- 优化带背景音乐视频的断句。
- 连续讲话时每约 3 秒生成预览译文，断句后补齐最终译文；仅原文模式不请求翻译。
- 关闭主窗口会同时停止字幕和退出后台服务。

开发版保持免安装，直接使用 `dist/WinToolbox-portable/WinToolbox.exe` 或已有桌面快捷方式，设置和模型保留在原 data 目录。

详细结果见 [真实 API 功能测试](REAL-API-VALIDATION.md)。本次实际验证了系统收音、云端转写及翻译、窗口控制，以及文件转写和带引用的资料问答；没有进行数小时连续播放压力测试。
