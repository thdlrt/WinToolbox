# WinToolbox 0.7.1

- 修复旧版升级后空知识库无法接入唯一云端库的问题。非空异库可选择合并，或保存恢复副本后使用远端覆盖；远端读取、校验完成后才切换本机。
- AI 聚合账户、额度查询凭据和调用配置加入加密自动同步。不同字段离线修改可自动合并，同字段和删除冲突提供版本选择，采用前保留本机副本。
- 扩大完整配置备份范围，包含聚合、快捷菜单、机器人、挂载、桥接、文件夹同步规则和已保存凭据等功能配置。接收设备重新保护凭据；文件夹规则恢复后先检查路径再启用自动执行。
- 旧目录迁移显示具体错误，提供旧连接账号与密码修复入口；当前目录继续同步。消除记账页同一迁移错误的重复提示。
- 继续读取 v2 Windows/Android 配置及旧版备份。v3 功能扩展需要更新后的 Windows 客户端。当前 WebDAV 接入连接保持接收设备配置。

Windows 发布附件仅安装包和 SHA-256 校验文件。安装升级保留已有数据；覆盖、合并和配置恢复均保留恢复副本。请在原设备和接收设备均更新后使用新增同步功能。
