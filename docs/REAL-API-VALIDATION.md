稳定字幕版本再次播放同一视频前 61 秒：连续讲话期间观察到“我们迈出了巨大的步伐，选择前往月球”“我们正在书写美国探索的下一个篇章”等中文预览随原文更新，暂停后补齐最终译文。播放已暂停，字幕采集已停止。

真实系统收音验证截图包含第三方视频画面，因此不随公开源码仓库分发。

## 本次修复

- 字幕启用百炼多阈值 VAD，使用 400 ms 静音断句阈值，减少带背景音乐视频的过长分句；会议模式保持原参数。
- 长段未断句语音每约 3 秒最多一次预览翻译，仅一个预览请求在途，取末尾最多 600 字符；整句确认后补齐最终译文，旧预览不能覆盖最终结果。
- 中文保留最近完成的译文，新一条原文识别中不会使中文消失；晚到译文不倒退。
- 长字幕按窗口宽度和字体显示末尾最新内容。
- 关闭主窗口时结束程序及音频会话，避免辅助窗口使后台进程残留。

此次真实 API 验证当时有 126 项 Python 测试、40 项前端字幕断言和 3 项原生窗口测试通过；0.1.20 发布前的完整回归已扩展到 336 项 Python 测试。开发交付使用固定免安装目录，保留相邻 data。
