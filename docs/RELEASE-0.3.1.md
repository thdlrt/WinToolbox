# WinToolbox 0.3.1

记账页面移除持续累积的“同步与导出任务”历史列表，只显示当前同步状态和最近一次导出的进度、错误或结果入口。

- 自动内存清理直接在工具箱内设置：支持占用阈值、定时间隔、最短间隔和独立清理模式。
- 手动及自动清理均复用工具箱原生组件，不再下载、打包或启动 Mem Reduct。
- 修复扩展 Windows 路径导致清理组件在启动时崩溃的问题；失败日志包含退出码和组件输出。
- 自动清理默认关闭，仅在工具箱运行期间生效；未启用清理授权组件时不会在后台弹出 UAC。
- 保留现有账目、附件、同步配置及本地数据。

首次使用内存清理时，在内存清理页点击“启用免重复授权”并完成一次 Windows 授权。旧 Mem Reduct 若仍在托盘运行，请自行退出，新版工具箱不再使用它。
