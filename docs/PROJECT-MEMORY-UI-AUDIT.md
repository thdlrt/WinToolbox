# 项目记忆界面检查与精简

日期：2026-09-21。范围：本次新增的项目记忆完整主流程、首页入口，以及全应用共用弹窗组件。保留既有配色与工具箱其他功能，没有改动用户实际记录进行测试。

## 检查与处理

| 步骤 | 原问题与修改 | 验证结果 |
|---|---|---|
| 1. 首页与项目列表 | 顶部六个等权按钮；导出等低频功能移至“更多”，一次性迁移入口已移除，日常保留登记、同步与设置。位置和订阅移入项目设置，保留每项目筛选。 | 入口、搜索、反复点击当前项目、空状态均通过。 |
| 2. 知识与任务编辑 | 原编辑表单在列表下面，正文和保存按钮常在首屏以外。改成独立编辑窗，保存栏固定，增加 Markdown 表格/代码/列表预览和 Ctrl+S。 | 连续输入、保留知识类型编码、中文类型名称、完成即归档、历史查看、附件与版本参数通过。 |
| 3. 同步与远程设置 | WebDAV、SSH、AI 长表单混排，技术 ID 占据首屏。改为三个页签，库标识与加入已有库折叠。 | 页签与方向键切换、隐藏控件不可聚焦、同步防重复和停止通过。 |
| 4. 冲突与失败恢复 | 强化未保存提示、读取错误重试和失败后的草稿保留。修复关联 ID 输入逗号立即消失，以及重复点击当前项目清空列表。 | 保存失败保留草稿、取消放弃、重试恢复、两个版本合并、父版本完整传递通过。 |
| 5. 原则与共享弹窗 | Modal effect 原本依赖每次重建的 onClose，输入时反复重置焦点。改为稳定监听、最新回调引用，过滤隐藏/禁用控件，处理顶层弹窗焦点环。 | 连续打字、原则编辑保存、Tab 回绕、Esc 与关闭恢复焦点通过。 |
| 6. 深色与窄窗口 | 统一主题变量、文字层次、边框、留白和控件密度。 | 1280×800 与 940×640 截图已检查；深色主题可读、无页面横向溢出、保存栏可见。 |
