# WinToolbox 0.4.1

统一应用数据同步与配置备份，简化设置和记账操作。

- 记账、网络诊断配置和项目记忆接入统一同步管理器：启动同步、本地修改合并触发、定时同步、失败退避重试，共用状态和生命周期管理。自动同步不再刷任务记录。
- 左下角新增同步图标，点击立即同步；悬停查看距上次成功同步的时间、正在同步或失败原因。移除设置中的自动同步面板及各模块重复入口。
- AI 供应商、功能模型和密钥并入配置备份，使用已保存的 WebDAV 密码加密。Windows 与 Android 共用不可变备份目录，恢复前预览确认；同平台恢复设置与 AI，跨平台仅恢复共享 AI，保留本机专属功能配置。
- 兼容旧配置备份和旧独立 AI 配置，支持恢复前版本检查、失败回滚；应用记录、附件和当前连接不随配置恢复覆盖。
- 记账新增近3月、近半年快捷区间；新增/编辑条目改用紧凑表单，附件只加入待保存列表。底部保存一次提交条目与附件，成功关闭，取消不写入，失败可安全重试。
- Windows 软件内更新改为在原目录覆盖安装，无需卸载，保留数据，成功后重启。
- PC 模型设置只展示 PC 功能，保留同步数据中的移动端专属模型。

已通过后端全量测试、前端行为检查、Android/Windows 实际 WebDAV 双向配置恢复与密钥保留测试。文件中转与目录同步仍按用户选定的文件/规则执行，不会因为点击数据同步而上传任意目录。

配套 AndroidToolbox 0.6.2。详见 [统一数据同步](DATA-SYNC.md) 与 [配置备份协议](CONFIG-BACKUP.md)。
