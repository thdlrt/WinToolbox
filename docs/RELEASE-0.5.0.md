# WinToolbox 0.5.0

新增选区快捷菜单与快捷脚本，减少后台占用，改进悬浮球和启动体验。

- 长按中键、侧键或自定义键盘组合键打开快捷菜单；支持固定工具入口与托盘开关。
- 「文件整理」替换为「快捷脚本」，提供 11 项带图标的内置功能和本地脚本入口，可按文本、文件、文件夹等条件推荐。解散文件夹先预览，拒绝覆盖冲突，失败时尝试回滚。
- 快捷翻译独立使用阿里云 Qwen3.8-Flash，支持单词音标、释义和段落翻译。已是目标语言时静默跳过，过滤密码框、链接、邮箱和疑似凭据。
- 悬浮球闲置后仅保留低亮度细环，定时微移；可在 5 分钟后自动隐去，鼠标移入恢复。开机显示悬浮球，主界面保留在托盘。
- 页面按需加载，隐藏窗口降低缓存预算，停止不可见页面轮询；选区组件按需运行，快捷菜单隐藏后释放窗口。
- 新增飞书消息桥接与来源对话路由，按配置规则继续对应 Codex 对话。
- 简化重复提示和空状态文案，改进工具图标、侧栏排序、同步反馈及内存清理组件。

## 下载与更新

- `WinToolbox_0.5.0_x64-setup.exe`：Windows 安装版。
- `WinToolbox-0.5.0-portable.zip`：便携版，解压运行 `WinToolbox.exe`。
- `SHA256SUMS.json`：下载文件校验值。

更新保留原有 data 目录。发布包不包含个人设置、密钥、模型或使用记录。飞书桥接需自行配置本机 CLI 与规则；云翻译需配置对应供应商。
