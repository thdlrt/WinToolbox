# WinToolbox 0.3.0

WebDAV 改为一个连接、一个根目录。配置备份、记账、诊断配置、文件中转站及项目记忆自动使用服务子目录，无需分别设置账号和远端路径。

- 设置区分“配置备份与恢复”和“数据自动同步”。配置恢复需手动确认，只覆盖配置，不替换业务数据。
- 新配置备份放入 `config-backups/windows`；旧根目录的备份仍可读取配置。
- 文件中转站统一使用 `file-relay`，移除独立连接和目录选项。旧目录文件自动复制迁移，原文件与同名冲突版本保留。
- 记账保留已有字段合并、冲突处理和附件校验协议。
- 保留 Windows 本地完整备份入口。

请让 AndroidToolbox 0.5.0 使用相同 WebDAV 连接和根目录。详见 [WebDAV 使用说明](WEBDAV.md)。
