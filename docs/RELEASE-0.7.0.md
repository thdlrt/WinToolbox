# WinToolbox 0.7.0

本次整合 AI 聚合、硬盘挂载、机器人联动与消息桥接等更新，并修复快捷菜单弹出前等待选区和剪贴板的问题。

- **快捷菜单**：慢选区先显示菜单和读取状态，再补齐动作；剪贴板文字在菜单出现后读取。修复长按松开时误取消读取、预建窗口丢失已记住选区的问题。新增剪贴板 OCR、剪贴板翻译和划词选区记忆，翻译沿用独立功能模型设置，本地模型预设补齐账目导入功能分配。
- **AI 聚合**：统一查看多个平台的额度、模型与本机用量，支持账户接入和只监听本机、需要独立 Key 的 OpenAI 兼容 Chat Completions 代理。各平台额度独立展示；上游能力和实际账号权限以服务响应为准。
- **硬盘挂载**：支持 SFTP / WebDAV 网络盘符、只读、断线重连和自动挂载；随包提供 rclone，首次使用仍需安装 WinFsp。
- **StackChan 与设备状态**：加入设备面板、任务状态提醒、屏幕与在场检测，以及拓竹打印状态接入。修复状态快照保存前提前进入空闲的竞态。需要使用者配置自己的设备与账号；不代表所有硬件组合均已完成长期验收。
- **消息桥接**：增加 QQ 机器人中转，改进飞书来源识别、会话路由及回复处理。接入需要使用者自行绑定机器人和目标对话。
- **记账与文件中转**：改进附件、账目导入和共享、下载进度及失败反馈；新增连接现有桌面后端的 JSON CLI。
- **项目记忆与快捷脚本**：完善知识治理、CLI 入口和同步脚本。移除桌面旧 Shizuku 入口和随包 ADB 组件。

## 安装与升级

下载 `WinToolbox_0.7.0_x64-setup.exe` 安装或覆盖升级，保留原有配置和记录。`SHA256SUMS.json` 提供对应安装包的 SHA-256。此次公开附件仅包含 Windows x64 安装包和校验文件。

安装程序需要 WebView2 Runtime；缺失时会尝试联网安装。大型模型、WinFsp 和需要用户账号的服务仍需按功能单独配置。

## 验证边界

本轮通过 1098 项后端测试、17 项原生测试和 20 组前端回归；安装包与本地便携目录均通过隔离 Python、8 项 RPC 和随包 FFmpeg 冒烟检查。发行验证记录见 [VALIDATION.md](https://github.com/thdlrt/WinToolbox/blob/v0.7.0/docs/VALIDATION.md)。自动测试和安装包检查不代表所有云端模型、私人服务或实体设备组合均已完成实测。快捷菜单原生冷窗口的单次可见时间约 120 ms，属于合成文件入口；用户反馈的约 10 秒鼠标长按延迟本次未稳定复现，不将该数值作为长按全链路性能承诺。
