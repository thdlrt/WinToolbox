# WinToolbox 0.1.3：实时字幕

新增“实时字幕”，用于电脑播放的直播或无字幕视频。只采集选定系统播放设备，不打开麦克风，不录音、不保存字幕历史，不自动回答节目中的问题。

用法：设置好百炼或本地预设 → 实时字幕 → 选择播放设备 → 开始字幕。独立窗口置顶、透明、无边框，不抢视频键盘焦点；支持双语、仅译文、仅原文，以及字号、背景不透明度、拖动、缩放和鼠标穿透。

- Ctrl+Alt+L：显示字幕窗并解除穿透。
- Ctrl+Alt+C：显示/隐藏字幕窗，识别继续。
- 托盘“显示并解锁字幕窗”和“停止实时字幕”提供快捷键之外的控制。
- 停止或关闭字幕窗结束采集；打开实时助手前需先停止字幕。
- 独占全屏播放器可能覆盖字幕窗，请使用窗口或无边框全屏。

字幕按最新句显示，原文先出、译文按句补齐；旧句晚到的译文不会使画面倒退。翻译失败继续显示原文。原文模式不调用翻译模型，后台字幕缓存和翻译队列均有数量上限。

验证：120 项 Python 测试通过；3 项原生窗口 DPI/工作区定位测试通过；11 项前端字幕状态断言通过。使用上一版安装的轻量本地模型，将本地合成测试语音直接送入真实 LocalASR，再由 Qwen 本地翻译；验证原文模式不调用语言模型，停止和重开相互隔离、不生成会话录音或历史。真实输出包含 “Please send the report today.” → “请今天发送报告。”。

控制页在 1280×860 和 940×640 检查无横向溢出，900×190 悬浮视图检查透明背景、双语显示和停止清空。截图为隔离测试数据，未采集用户正在播放的音频。原生透明/置顶/穿透通过 Tauri API 实现并完成编译；没有为验证而关闭当前用户程序或抢占桌面。本次未用实际计费 API 或长直播进行持续测试。
