# WinToolbox

Windows 语音与效率工具箱。统一处理本地音视频、实时字幕、实时双语问答、Codex 模型配置和可安装扩展。实时问答可选择会前准备的资料库。

[图文使用手册](output/pdf/WinToolbox_图文使用手册与设计说明.pdf) · [版本记录](docs/RELEASE-0.1.21.md) · [参与开发](CONTRIBUTING.md)

## 开发阶段快速使用

安装 Node.js、Rust MSVC 工具链和 [uv](https://docs.astral.sh/uv/) 后，在 PowerShell 运行：

```powershell
git clone https://github.com/thdlrt/WinToolbox.git
Set-Location WinToolbox
.\scripts\dev.ps1
```

首次运行会创建 `core/.venv`、安装前后端依赖并启动开发窗口。开发数据默认保存在 `dist/WinToolbox-portable/data`；前端修改即时刷新，Python/原生代码修改会重启开发程序。不要同时运行开发版和免安装版。

需要更新本机固定免安装目录时，先退出程序，再运行 `.\scripts\package.ps1 -PortableOnly -SkipInstall`。它会更新 `dist/WinToolbox-portable` 并保留相邻的 `data`，不会生成 Release ZIP。

## 安装与首次使用

1. 从 [GitHub Releases](https://github.com/thdlrt/WinToolbox/releases) 下载安装程序，或完整解压免安装 ZIP 后运行 `WinToolbox.exe`。迁移便携版时复制整个程序目录及相邻 `data`，不要只复制 EXE。
2. 打开“设置 → 模型”。选择“阿里云百炼 API”填入 API Key 并应用，或选择“本地模式”安装一套预设后使用。
3. 文件工作台和实时助手自动使用所选模式。其他 API 服务和功能模型分配收在“高级设置”；原有配置保留。

百炼模式会在同一页面显示本机 API 用量：今日、本月、累计请求数，接口返回的 Token 数，以及实时/文件语音时长。统计从 0.1.6 开始，只覆盖这套 WinToolbox 发出的请求；阿里云账户总用量、余额和最终费用仍以控制台为准。

本地提供三套预设：轻量（建议 8 GB 内存、CPU）、均衡（建议 16 GB 内存、8 GB NVIDIA 显存）、高质量（建议 32 GB 内存、16 GB NVIDIA 显存）。这些是保守的配置建议，实际速度随任务和同时运行的程序变化。首次安装下载运行包及模型，完成后转写、翻译、问答和资料检索走本机模型，不会自动回退到云端。配音、说话人区分等附加能力另行安装。

程序从空白数据开始，不读取或迁移旧 AItext 的密钥、设置或媒体。Codex 页面点击“扫描模型”后读取指定 Codex 配置；修改需在界面预览后点击应用。

基础运行环境和 FFmpeg 随软件提供。Windows 安装程序检查 WebView2，缺失时联网安装。便携版需要已有 WebView2 Runtime。大型本地模型、GPU 运行包及 Office 转换环境在设置的模型中心按需安装，模型安装需要联网；模型运行包可单独导出以供另一台 Windows x64 电脑导入。

## 常用流程

**Shizuku**：发现局域网手机或填写无线调试连接地址，点击“一键启动”。首次展开无线配对，填手机配对弹窗地址和六位码后“配对并启动”；配对端口不同于连接端口。需要 Android 11+、同一局域网和手机已安装 Shizuku。软件内置 ADB，配对码不写入记录；重开无线调试后端口可能变化，可刷新发现重新选择。

**记账**：选择起止月份，新增支出或转账收入；支出可标记等待报销、已报销或不可报销。支持关键词、类型、状态、分类和币种筛选。区间应均摊金额＝（消费总额－已报销总额）÷2，按分四舍五入；与转账收入比较，显示还需转入、多转金额或已结清。等待报销暂不扣除，不同币种分别计算，区间汇总不受列表筛选影响；均按条目日期归属月份。条目可添加多份发票、收据和支付记录，附件保存副本并随本地备份及 WebDAV 同步。

**口语练习**：新建段落，粘贴英文，选择音色后保存或生成。每个段落可编辑、删除、移入分类文件夹；选词和选句生成的片段保存在所属段落内。展开片段即可回放，支持调速和循环。点击单词显示离线美式词典音标，未收录的词会明确提示。

**音标教学**：在口语练习中进入，包含识读音标、六组关键发音、学术词重音、听辨小测和汇报跟读。45 段示范音频随软件提供，可离线慢放；学习进度和自定义稿随应用备份及 WebDAV 同步。支持录音回听及手动导出，录音为临时本机数据，不自动上传或评分。

保存文字和移动分类不调用 API；普通生成复用已有缓存，修改后的新句子或新声音需要合成。选择“重新生成”会再次调用 API 并保留旧音频。删除条目归档记录，删除分类则将段落移到未分类。旧版记录保持独立，不自动猜测片段归属。

音色下拉按当前模型显示百炼官方系统音色，也可填写自定义 ID。目录不是账户克隆音色的实时查询。已有音频可离线回放，变速和循环不产生合成费用。

**直播 / 视频实时字幕**：打开“实时字幕”，选择电脑播放设备与原语言（默认自动识别），再点击“开始字幕”。英文视频可选“英语 → 中文”。置顶窗口等待文字稳定后配对同句译文，长句从头到尾分屏，留出阅读时间再切换。翻译超时显示本句原文；明显积压时跳过较早待播字幕并提示。可切双语/译文/原文、调整字号和背景、拖动和缩放。鼠标穿透后按 `Ctrl + Alt + L` 或托盘“显示并解锁字幕窗”恢复操作；`Ctrl + Alt + C` 仅显示/隐藏。停止或关闭字幕窗结束采集。字幕不打开麦克风、不保存录音，与实时助手互斥。独占全屏播放器请改用窗口或无边框全屏。

**本地音视频**：添加文件 → 勾选转写、翻译等步骤 → 开始处理。模型自动使用设置中选定的 API 或本地模式。进度、取消、重试和结果文件都在当前工具页面，字幕可编辑并导出 SRT、VTT、TXT、JSON。

**实时助手**：选择系统声音、麦克风或双路，按需选择资料库，点击开始。双路模式默认从系统声音识别听众问题，麦克风用于上下文。默认保留文字和分段录音；会话历史可回听或在文件工作台重新转写。网络中断时录音继续，重连后自动补转写缺口，历史问题不会再次触发回答。补转写使用文件识别服务，进度、失败原因和结果在实时助手页面查看。

需要依据资料回答时，点击实时助手顶部“资料库”→“新建”，用“导入并建立索引”加入少量相关文档。等待状态为“已就绪”，再在“使用资料库”中选库并开始会话；不需要时选“不使用资料库”。把导入和索引放在会前，可减少现场准备时间；回答仍需实际检索和模型生成。没有独立的资料问答页面，运行中先停止会话再切库或修改资料。

**配音**：Edge TTS 或百炼 Qwen TTS 可直接使用对应云服务；CosyVoice 是本地模型，需要先安装并选择合适参考音频。背景分离使用独立 Demucs 运行包。

**视频增强**：安装 Real-ESRGAN Vulkan 运行包，支持有兼容 Vulkan 驱动的 GPU。输出不超过 4K。具体支持情况以运行包检测和实际任务结果为准。

**文件整理**：预览逐个源文件与目标文件，再执行。重名和外部修改会拦截，不静默覆盖已有文件。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl + Alt + Space | 立即回答最近问题 |
| Ctrl + Alt + Escape | 取消当前答案 |
| Ctrl + Alt + ← | 在实时界面查看上一题 |

快捷键被其他应用占用时，可使用界面上的同名按钮。悬浮窗支持置顶、缩放和移动。

## 本地模型

- Whisper large-v3-turbo / large-v3：多语种转写与词级时间戳。
- Qwen3-ASR 0.6B / 1.7B：本地分段转写，配套强制对齐器；不要求安装 WSL。
- SenseVoiceSmall：中、英、日、韩和粤语快速识别。
- Pyannote：说话人区分；模型需 Hugging Face 访问权限。在 API 服务中添加名称为 `Hugging Face` 的服务，类型选 OpenAI 兼容，地址填 `https://huggingface.co/api`，密钥填 Hugging Face 令牌。
- CosyVoice、Demucs、Real-ESRGAN 和 LibreOffice：独立安装，互不修改系统 Python/Conda 环境。

API 模式无需下载这些模型。本地实时模式为分段识别，延迟与模型大小、显卡和语音断句有关；不会标成原生流式服务。

## 数据、备份和升级

**WebDAV 同步**：在设置 → 数据与备份中填写 WebDAV 地址、远端目录和账号，保存后测试连接。点击“上传快照”保存当前设置与应用数据；默认包含录音和朗读缓存，可选包含模型。换电脑后配置同一连接，读取快照并选择恢复。恢复前自动创建本地备份，完成后重启工具箱。每次上传保留独立快照，不自动合并多台电脑的修改。

WebDAV 密码只在本机加密保存。需要一起迁移 API 密钥时，勾选“包含 API 密钥”并设置至少 8 位的备份密码；第二台电脑恢复时输入该密码。未勾选时，服务地址、模型等设置仍会同步，但 API 密钥需要另行填写。

安装版默认数据位置：`%LOCALAPPDATA%\WinToolbox`。便携版通过 EXE 相邻的 `portable.flag` 使用 `data` 目录。文件输出可选择其他目录。

设置中的备份可以包括任务、资料、录音、输出及模型。包含 API 密钥时必须设置备份密码，密钥在日常使用时由 Windows 当前用户加密保护。跨用户或跨电脑不要直接复制密钥存储，应使用加密备份恢复或重新输入密钥。

恢复备份会检查内容与路径，开始前需要其他任务和实时会话停止。数据恢复与数据库路径会针对当前目录调整。外部输出目录中的大文件请另外复制，或在恢复后重新定位。

升级时退出旧版，使用新版安装程序。卸载程序不默认删除数据。故障日志位于数据目录 `logs`，任务的处理日志在对应任务目录。

## 开发

需要 Node.js、Rust MSVC 工具链、uv。运行：

```powershell
.\scripts\dev.ps1
```

后端协议：

```powershell
.\core\.venv\Scripts\python.exe -m toolbox --data-dir .\.build\dev-data
```

测试与打包：

```powershell
uv run --project core pytest tests
.\scripts\package.ps1
```

实现接口见 `docs/CONTRACT.md`，工具包模板见 `examples/file-hash`。目录职责：`desktop` 为桌面 UI 与原生壳，`core/toolbox` 为后台，`tests` 为自动测试，`scripts` 为开发与发布工具。

## FN 远程访问（Windows TCP 试验版）

工具首页 → FN 远程访问，填写设备专属 FN Connect 域名与飞牛管理员账号，选择仅回家或全局出口。点击连接后可测试回家连接；SOCKS5 位于 127.0.0.1:18792。需要系统应用流量接管时启用 TUN，并完成 Windows 管理员授权。NAS 端需要局域网桥 0.4.0，在回家 VPN 页允许客户端隧道并设置局域网范围；全局出口还需要 NAS 端单独允许。

不支持 FN Token 的 API 工具可使用“API 端口映射”：为指定的局域网 IPv4 和端口生成 `127.0.0.1:本机端口`，工具只需改用这个本机地址。每条映射可单独编辑、启用、停用和删除，断线后停止监听，重新连接时恢复已启用规则。映射始终只监听本机并固定走仅回家范围；目标必须在 NAS 插件下发的允许网段内。HTTP、HTTPS、TCP 和 WebSocket 都按原始 TCP 转发，HTTPS 工具仍需处理目标证书域名问题。映射规则随备份和 WebDAV 快照迁移，不保存或暴露 FN Token。

点主窗口关闭默认隐藏到托盘，连接继续运行。从托盘菜单的退出彻底结束；退出时停止 TUN 和隧道。密码、会话仅驻留内存，不进入任务记录、配置与备份。程序重启后重新连接。当前只转发 TCP；UDP、IPv6、广播发现和双重验证尚未接入，Android APK 尚未交付。
